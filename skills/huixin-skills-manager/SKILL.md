# 汇芯技能管家

本技能只提供桌面工具的安装与使用指引；通过技能安装命令安装本文，不会自动安装应用。桌面应用基于 Aman Mittal 的 SkillsBar 二次开发，必须保留原作者和上游 Apache-2.0 许可，不宣称完全原创。

## 先确认本机状态

检查 macOS 版本、Xcode 命令行环境和是否已有“汇芯技能管家.app”。已安装时先查看，避免重复下载或同时启动旧版 SkillsBar。不要读取账户密钥、浏览器会话或无关知识库。

## 获取与构建

源码仓库：https://github.com/sixwei2025/huixin-skills-manager 。在用户选择的工作目录克隆，进入仓库后阅读 README，运行 `bash scripts/build.sh`。构建脚本会生成应用和安装包，并执行 `--self-test`。构建失败如实报告，不用旧产物冒充新版。

应用在 `build/distribution/汇芯技能管家.app`。复制到用户选定的应用目录后打开；快捷键为 ⌥⇧S。本版尚未进行 Apple 开发者签名与公证，不能关闭系统安全保护来规避提示。

## 管理与排查

- 四个来源必须读取各自真实目录，不能把旧 Claude Code 或 Pi 数据换标签后冒充新工具。
- 中文显示名与原始调用名分开，只改显示映射，不批量重命名或改写原有技能文件。
- 中文映射位于 `SkillsBar/Models/Skill.swift`；修改后重建，运行自检和目录扫描核验。
- 同时出现 SkillsBar 与汇芯技能管家时，保留新版运行；退出旧版之前确认它没有未保存的操作，不删除原版及配置。
- 使用记录暂只核验 Codex；其他宿主的次数显示未知，不填0。账号额度另用相应额度工具。
- 公开示例与截图排除个人路径、客户信息、凭证和知识库正文。

## 按工作流与项目整理技能

打开“工作流分类”，查看按名称、目录名及说明关键词自动归类的技能。规则只做本地分类，不调用模型、不执行工作流；结果不准确时，在卡片右侧菜单“调整工作流归类”纠正，或恢复自动归类。若要卸载某个全局技能，可在卡片右侧菜单、右键菜单或详情页点击“删除技能”，会移至废纸篓并同步移除 Gemini、Codex、Grok Bot、WorkBuddy 中的对应副本与软链接。

点击“我的分类”旁的加号，新建分类，编辑名称后保存。进入“添加技能”勾选需要的技能，完成后可按来源筛选、搜索、移出。一个技能可以加入多个分类；删除分类不会删除技能文件。原收藏夹自动沿用，分类保存在本机应用偏好设置中。真实路径相同的多来源链接共享归类；路径发生变化后可能需要重新加入。
